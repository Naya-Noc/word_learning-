Ficdeck — читалка скачанных фиков со словарём и карточками

На компьютере: просто открой index.html в браузере.

На iPhone (один раз, дальше всё работает без интернета и VPN):
1. На github.com создай публичный репозиторий, например ficdeck.
2. Загрузи в него все файлы из этой папки (Add file → Upload files).
3. Settings → Pages → Branch: main, папка / (root) → Save.
4. Через минуту открой в Safari адрес https://ТВОЙ-НИК.github.io/ficdeck/
5. Поделиться → «На экран Домой». Открывай Ficdeck с иконки.

Фики добавляются кнопкой «Добавить фик» (EPUB, HTML, TXT, FB2 из «Файлов»).
Слова хранятся только на устройстве — время от времени сохраняй резервную копию в настройках.
